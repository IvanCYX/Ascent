Ascent for iPhone

Every web screen redrawn for a 393 × 852 phone. The paper-and-ink editorial layer carries the content; Liquid Glass owns navigation and controls. Tall frames show a whole scroll, and the red dashed line marks the bottom of the first screen. Use the controls to flip light and dark and to try accent colours across every frame.

Information architecture

Five tabs: Today, Plan, History, Body and Settings. No tab root has a toolbar button for settings or appearance; that all lives in the Settings tab. Logging is an action, so it lives behind the + as sheets. Competitions, the calendar and taper suggestions live in Plan under a Today | Season switch.

1 · Navigation and the + button

The + is its own glass circle floating 10 pt above the tab bar's centre. It is an action, so it stays out of the tab bar. When the bar minimises on scroll, the + drops into the freed bottom row. The live-session timer depends on the phone. Without a Dynamic Island, it floats 8 pt above the +. With one, it lives in a Live Activity. iOS only shows that in the island once you leave the app, so inside the app the + gets an accent ring instead.

2 · Quick-add flows

Gym send end to end: selector → start session → log a send → sent. Then the Camp5 tally, board, review, pain and rehab flows.

3 · Tabs

Full scrolls. The content keeps the web's order and copy; wide tables became two-line rows, and the dashboard's two columns now stack. Plan has a new Season view with a calendar, competitions and a taper plan that shortens your sessions as the comp nears.

4 · Settings

Settings is now the fifth tab. It is the one screen that is entirely control layer, so it uses the system grouped Form on paper-tinted backgrounds. The accent colours navigation, primary actions and every chart. Selection state stays ink. Injury red and hold colours never change.

5 · Face ID app lock

Optional and off by default. The lock uses .deviceOwnerAuthentication, so iOS supplies the passcode fallback. A privacy cover replaces the app-switcher snapshot whenever the lock is on.

6 · Widgets

"Limited" shows sessions this week, the weekly streak and weeks to the next comp. It hides grades, gym names, injuries, pain and rehab. Redaction applies only while the Face ID lock is on. Home Screen sizes appear locked in StandBy and on iPad's Lock Screen.
